每一个框是一个芯片/模块，框里的数字是引脚编号，箭头指向它连到哪。
> GND = 全部连一起，3.3V = 系统 3.3V，5V = 系统 5V，VBUS_PD = USB PD 协商后的电压(5~20V)

## 二、STM32G030K6T6（LQFP-32）—— 所有引脚连接

> 注意：主控用的是 **STM32G030K6T6**（LQFP-32，32 脚封装），不是 TSSOP-20 的 F6P6。
> (NC) = 未连接 / 悬空。

```
                    ┌───────────────────────────────────────┐
                    │           STM32G030K6T6               │
                    │           LQFP-32                     │
                    │                                       │
        (NC) ───────┤1  PB9                          PB8 32├──── OLED_RESET（接 OLED 的 RST）
        (NC) ───────┤2  PC14-OSC32IN                 PB7 31├──── I2C_SDA → INA226 + OLED
        (NC) ───────┤3  PC15-OSC32OUT                PB6 30├──── I2C_SCL → INA226 + OLED
   3.3V ────────────┤4  VDD/VDDA                     PB5 29├──── (NC)
   GND ─────────────┤5  VSS/VSSA                     PB4 28├──── (NC)
   R16 10kΩ ────────┤6  NRST（复位）                 PB3 27├──── CH224K CFG3
   按键 UP ─────────┤7  PA0                           PA15 26├──── (NC)
   按键 DOWN ───────┤8  PA1                           PA14 25├──── SWCLK（SWD 排针，兼 BOOT0）
   按键 OK ─────────┤9  PA2                           PA13 24├──── SWDIO（SWD 排针）
   调试 UART_TX ────┤10 PA3                           PA12 23├──── (NC)
   调试 UART_RX ────┤11 PA4                           PA11 22├──── (NC)
   LED ─────────────┤12 PA5                           PA10 21├──── (NC)
   PWM ─────────────┤13 PA6                           PC6 20├──── (NC)
   NTC ─────────────┤14 PA7                           PA9 19├──── (NC)
   CH224K CFG1 ─────┤15 PB0                           PA8 18├──── S8050 基极（MOSFET 急停）
   CH224K CFG2 ─────┤16 PB1                           PB2 17├──── (NC)
                    └───────────────────────────────────────┘
```

### MCU 电源和调试详解

```
引脚 4 (VDD/VDDA):
    │
    ├── 3.3V 电源
    ├── 100nF 电容 ── GND   ← 贴片电容，紧挨引脚 4 放
    ├── 100nF 电容 ── GND   ← 再放一个
    └── (如果有多个 VDD 脚，每个脚都配一个 100nF)

引脚 5 (VSS/VSSA):
    └── GND（直接连地平面）

引脚 6 (NRST) 复位电路:
    NRST ──┬── R16 10kΩ ── 3.3V   (上拉)
           └── C18 100nF ── GND   (去抖 / 上电延时)

SWD 4P 排针（J2，用来烧录程序）:
    排针 1 ── 3.3V
    排针 2 ── PA13 (SWDIO)
    排针 3 ── PA14 (SWCLK)
    排针 4 ── GND
    注意：PA14 兼作 BOOT0，复位/上电时它的电平会影响启动方式。
```

## 三、CH224K（SOT-23-6）—— PD 触发芯片

```
                    ┌─────────────────────┐
                    │       CH224K        │
                    │     SOT-23-6        │
                    │                     │
       3.3V ───────┤1  VDD     VBUS  6├──┤
       C2 100nF    │                     │  ├── USB-C 的 VBUS 脚
       ── GND      │                     │  ├── C3 1μF ── GND
                    │                     │  └── VBUS_PD 网络（通往后面的电路）
       GND ────────┤2  GND     CFG3  5├──── PB3 (MCU 引脚 27)
                    │                     │
 MCU PB0 ──────────┤3  CFG1    CFG2  4├──── PB1 (MCU 引脚 16)
 (MCU 引脚 15)      │                     │
                    └─────────────────────┘
```

**CFG 引脚怎么控制（三态）：**

```
MCU 想要 HIGH:  GPIO 设为推挽输出，输出高电平
MCU 想要 LOW:   GPIO 设为推挽输出，输出低电平
MCU 想要 NC:    GPIO 设为浮空输入模式（不驱动，呈高阻态）

电压切换例子（设到 20V）:
  PB0(CFG1) = LOW   → 推挽输出低
  PB1(CFG2) = LOW   → 推挽输出低
  PB3(CFG3) = NC    → 浮空输入
  → CH224K 向充电器请求 20V
```

### LM358 恒流环路的完整接法（展开引脚 1、2、3）：

```
                           PWM 设定电压的产生
═══════════════════════════════════════════════════════════════

MCU PA6 (引脚 13) ── 输出 PWM 方波 (0V/3.3V 跳变, 10kHz)
  │
  ├── R7 100kΩ ──┬──→ 这个点叫 V_SET (平滑后的直流电压, 0~70mV)
  │              │
  │              ├── R8 2.2kΩ ── GND    ← 分压: 3.3V × 2.2/(100+2.2) ≈ 70mV  max
  │              ├── C11 10μF ── GND     ← 滤波电容，把 PWM 变成平滑直流
  │              └── C13 10nF ── GND     ← 高频噪声滤除
  │
  │         V_SET 最终范围: 0 ~ 70mV
  │         对应电流:        0 ~ 3.5A  (70mV / 20mΩ = 3.5A)
  │


                          恒流闭环控制
═══════════════════════════════════════════════════════════════

                         LM358
                      ┌──────────┐
                      │          │
    V_SET ───┬────────┤3 IN1+    │
             │        │          │
             │        │          │
    R6 10kΩ  │        │          │
             │        │      1 OUT├──┬── R4 100Ω ── R5 1kΩ ── MOSFET G 极
    GND ─────┘        │          │  │
                      │          │  └── C10 100nF ──┐
                      │          │                  │
    MOSFET S极 ──R9───┤2 IN1-    │                  │
    (采样电阻高端)     │          │                  │
            10kΩ      │          │                  │
                      └──────────┘                  │
                                                    │
    ┌───────────────────────────────────────────────┘
    │  (C10 的另一端，形成积分反馈)
    │


                          功率回路
═══════════════════════════════════════════════════════════════

  VBUS_PD (来自 USB PD 的 5~20V)
    │
    │
    │   ┌───────────────────────┐
    │   │  IRLZ44N MOSFET       │
    │   │  TO-220               │
    │   │                       │
    └───┤D (漏极)               │
        │                       │
        │         G (栅极) ─────┼── 来自 LM358 OUT → R4 → R5
        │                       │
        │         S (源极) ─────┼──┬─── R3 (20mΩ 采样电阻) ─── GND
        └───────────────────────┘  │
                                   │
                                   ├── Kelvin 检测线 → INA226 引脚 9 (VIN+)
                                   ├── Kelvin 检测线 → LM358 引脚 2 (经过 R9)
                                   │
                                   │    (R3 另一端)
                                   ├──── Kelvin 检测线 → INA226 引脚 10 (VIN-)
                                   └──── GND (功率地，大电流)
```

## 十、按键 ×3 + 状态 LED

```
  按键 UP (SW1):
      3.3V ── R18 10kΩ ──┬── MCU PA0 (引脚 7)
                         │
                         ├── 按键 ── GND
                         
  按键 DOWN (SW2):
      3.3V ── R19 10kΩ ──┬── MCU PA1 (引脚 8)
                         │
                         ├── 按键 ── GND
                         
  按键 OK (SW3):
      3.3V ── R20 10kΩ ──┬── MCU PA2 (引脚 9)
                         │
                         ├── 按键 ── GND

  工作原理:
    按键没按下 → 10kΩ 上拉到 3.3V → MCU 读到高电平
    按键按下   → 直接通 GND     → MCU 读到低电平


  状态 LED:
    MCU PA5 (引脚 12) ── R21 1kΩ ── LED 阳极
                                      │
                                    LED 阴极 ── GND
                                    
    PA5 输出高 → LED 亮
    PA5 输出低 → LED 灭
```

## 十一、可选扩展：NTC 温度检测 + 急停

```
  NTC 温度检测:
      3.3V ── R22 10kΩ (1%) ──┬── MCU PA7 (引脚 14, ADC 通道)
                              │
                              ├── C19 100nF ── GND (滤波)
                              │
                              └── NTC (10kΩ B=3950) ── GND
                                  
      NTC 贴紧 MOSFET 散热片安装，用导热胶固定


  MOSFET 急停 (硬件关断负载):
      MCU PA8 (引脚 18) ── R23 10kΩ ── S8050 基极 (B)
      
      S8050 集电极 (C) ──── MOSFET G 极
      S8050 发射极 (E) ──── GND
      
      PA8=高 → S8050 导通 → G 极拉到 GND → MOSFET 关断
      PA8=低 → S8050 截止 → G 极由 LM358 控制 → 正常工作
```

## 十二、完整连接速查表（按网络）

```
网络: GND
  连到: 所有芯片的 GND/VSS 脚、USB-C GND、去耦电容的 GND 端、
        采样电阻低端、按键低端、LED 阴极、SWD 排针

网络: 3.3V
  连到: STM32 VDD(4), CH224K VDD(1), INA226 VCC(8), OLED VCC,
        I2C 上拉电阻, 按键上拉电阻, NTC 上拉电阻

网络: 5V
  连到: LM358 VCC(8), AMS1117 输入

网络: VBUS_PD (5~20V)
  连到: USB-C VBUS 脚, CH224K VBUS(6), MP1584 VIN, MOSFET D 极,
        INA226 VBUS(3)

网络: I2C_SDA
  连到: MCU PB7(31), INA226 SDA(5), OLED SDA
        + 上拉电阻 R14 10kΩ → 3.3V

网络: I2C_SCL
  连到: MCU PB6(30), INA226 SCL(6), OLED SCL
        + 上拉电阻 R15 10kΩ → 3.3V

网络: SWDIO
  连到: MCU PA13(24), SWD 排针 J2 引脚 2

网络: SWCLK
  连到: MCU PA14(25), SWD 排针 J2 引脚 3

网络: OLED_RESET（可选）
  连到: MCU PB8(32), OLED 模块 RST 脚（5 脚 OLED 才有，4 脚没有就悬空）
```
